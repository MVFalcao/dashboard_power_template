Guia Interativo - dashboard-reporter

Guia em portugues para quem esta comecando. Mostra desde abrir o terminal ate gerar o relatorio final.

Escolha Seu Modo

Use este modo no Windows com executavel pronto.

Passo a passo:

  • Abra o PowerShell.
  • Entre na pasta do projeto com cd.
  • Execute o comando abaixo.
cd "C:\caminho\para\dashboard_power_template"

Linux/macOS:

cd /caminho/para/dashboard_power_template
.\dist\dashboard-reporter.exe quick-run --input template\Dashboard_50.xlsx

Use este modo quando estiver trabalhando no codigo fonte.

Passo a passo:

  • Abra o PowerShell.
  • Entre na pasta do projeto com cd.
  • Execute o comando Python abaixo.
cd "C:\caminho\para\dashboard_power_template"

Linux/macOS:

cd /caminho/para/dashboard_power_template
python -m dashboard_reporter.cli quick-run --input template/Dashboard_50.xlsx

Passo a Passo Para Iniciantes

0) Abrir o PowerShell

No Windows: pressione a tecla Win, digite PowerShell e abra o aplicativo.

1) Entrar na pasta do projeto

Copie e execute:

cd "C:\caminho\para\dashboard_power_template"

Linux/macOS:

cd /caminho/para/dashboard_power_template

Agora confirme se esta na pasta certa:

dir

Voce deve ver pastas como src, configs, scripts, template.

2) Gerar o .exe (somente na primeira vez) 
.\scripts\build_windows_exe.ps1

Quando terminar, o executavel fica em .\dist\dashboard-reporter.exe.

3) Rodar com 1 comando (mais simples) 
.\dist\dashboard-reporter.exe quick-run --input template\Dashboard_50.xlsx
4) Opcional: configurar banco Turso

Se nao configurar, o sistema cria banco local automaticamente em artifacts/quick-run/quick-run.db.

Para usar Turso remoto, crie um arquivo .env com:

TURSO_DATABASE_URL=libsql://SEU-BANCO.turso.io
TURSO_AUTH_TOKEN=SEU_TOKEN
5) Opcional: escolher motor de PDF

Padrao: auto (tenta xhtml2pdf, depois Playwright).

set DASHBOARD_REPORTER_PDF_ENGINE=xhtml2pdf
.\dist\dashboard-reporter.exe quick-run --input template\Dashboard_50.xlsx

Comando Rapido de Verificacao

Para verificar se deu certo, rode:

dir artifacts\quick-run

Os arquivos esperados sao:

  • report.html
  • report.pdf
  • metrics.json
  • ingestion_log.json

Se esses 4 artefatos existem, a execucao esta correta.

Modo Avancado

Quando quiser controlar cada etapa manualmente:

dashboard-reporter validate-config --config configs/dashboard_template.yaml
dashboard-reporter migrate-schema --config configs/dashboard_template.yaml --drop-normalized-candidates
dashboard-reporter run --input template/Dashboard_50.xlsx --config configs/dashboard_template.yaml --out artifacts/run --run-date 2026-03-07
